Bảng dữ liệu và phương thức
Chức năng: Trung tâm Cảnh báo AI

STT Tên bảng Thêm Sửa Xóa Truy vấn
1 ai_alerts (hoặc notifications) x x x

Giải thích luồng dữ liệu (Tích hợp AI/LLM):

1. Thu thập Cảnh báo (Cronjob / Trigger): Hệ thống backend có thể được cài đặt để chạy ngầm định kỳ (hoặc khi có thay đổi lớn). Nó thu thập dữ liệu (Kho, Doanh thu), gửi prompt qua API cho mô hình AI (OpenAI/Gemini). Kết quả trả về (cảnh báo cạn kho, thất thoát) sẽ được Thêm tự động vào bảng ai_alerts.

2. Yêu cầu phân tích tức thì: Khi Quản lý nhấn "Yêu cầu AI phân tích ngay", Frontend gọi API ép Backend lặp lại luồng trên ngay lập tức và Thêm các bản ghi cảnh báo mới (nếu có) vào ai_alerts.

3. Hiển thị và Xử lý: Màn hình liên tục Truy vấn bảng ai_alerts để hiển thị. Khi quản lý nhấn "Đánh dấu xử lý", hệ thống thực hiện lệnh Sửa cập nhật trạng thái bản ghi thành is_read = true (hoặc resolved) để loại bỏ thẻ đó khỏi tab "Chưa đọc".
